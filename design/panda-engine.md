# The panda engine moved

The learned line-walker project — the engine port, the trainer, the RL/interp
research and its design record (`panda-policy-net.md`, `panda-engine-map.md`,
`e5-plateau-research.md`, `e6-fair-expert-and-ladder.md`) — lives in its own
repo as of 2026-08-02: **[Ameya-bit/panda-engine](https://github.com/Ameya-bit/panda-engine)**.

This repo keeps: the runtime engine copy the page loads
(`assets/pandas/engine/`, rules expert only, synced from the engine repo), the
original `assets/pandas/pandas.js` behind `?engine=old`, and the site-side panda
docs (`panda-chaos.md`, `panda-choreography.md` — copies also exist in the
engine repo). Git history from before the split stays here.
