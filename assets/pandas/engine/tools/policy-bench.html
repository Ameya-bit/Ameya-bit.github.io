policy forward pass — main thread and worker

Two arms, two budgets. The main thread (?policy=nn-main) is held to Phase D's 1 ms — anything slower is a stolen frame. The worker (?policy=nn, the shipped path) is held to the pipeline deadline: the answer to the frame posted at decision k must land before decision k+1, i.e. round-trip < 100 ms, and a miss only costs a fallback tick, never a frame. Both arms run the shipped net.js against the shipped policy.bin, here, in whatever browser you opened this with.
